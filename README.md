# 💰 برنامه مدیریت مالی — نسخه Android (Kotlin)

نسخه‌ی موبایل برنامه مدیریت مالی با **Kotlin** و **Jetpack Compose**

## ✨ ویژگی‌ها

- 📊 مدیریت کارت‌های بانکی
- 💵 ثبت درآمد و هزینه
- 🔁 انتقال بین کارت‌ها
- 🐷 پس‌انداز
- 📩 پارسر هوشمند پیامک‌های بانکی
- 🔗 یادگیری خودکار پیامک‌ها
- 📈 نمودارهای مالی
- 💾 پشتیبان‌گیری
- 🎨 رابط کاربری مدرن با Jetpack Compose

## 🏦 بانک‌های پشتیبانی‌شده

- ✅ بانک سپه
- ✅ بانک پاسارگاد
- ✅ بانک اقتصاد نوین
- ✅ بانک صادرات
- ✅ بانک ملی
- توانیی شناسایی پیامک بصورت هوشمند برای بقیه بانکها با تعریف کاربر 

## 🛠️ تکنولوژی‌ها

- Kotlin 2.0.21
- Jetpack Compose
- Room Database
- DataStore
- Coroutines / Flow
- Material 3

## 🚀 اجرا

1. Android Studio باز کن
2. پروژه رو Clone کن
3. `Run` بزن
